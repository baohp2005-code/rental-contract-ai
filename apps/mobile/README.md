# apps/mobile

Đã có app thử nghiệm: chạy `npm run dev:web` hoặc `npm run dev:mobile` từ gốc repo. Chạy API riêng bằng `npm run dev:api`. Xem [docs/TRIAL.md](../../docs/TRIAL.md).

Không khởi tạo lại bằng create-expo-app; dùng mã nguồn hiện có trong thư mục này.
